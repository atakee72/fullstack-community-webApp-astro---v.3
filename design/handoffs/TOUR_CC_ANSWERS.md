## 1 + 2 · Finales Kapitel-Copy (24 Stationen, DE + EN) — inkl. Anker-Korrekturen

Gleiche Anatomie wie Forum: Kicker `FÜHRUNG · [KAPITEL]` / `TOUR · [CHAPTER]`, Titel + 1–2 Sätze Body, Fortschritt „n / N“ mit der ehrlichen Kapitel-Länge. Deutsche Anführungszeichen „…“ (U+201E/U+201C). Anker-Spalte = Zielvorschlag nach der Sicherheitsregel (Chrome + Top-Level-Controls, nie die n-te Karte).

**Anker-Entscheide zu CCs drei Wackelkandidaten (Frage 2):**
- **Kalender „Ziehen-zum-Anlegen“ → umbenannt zu „Termin anlegen“.** Anker = Monatsraster (Grid-Container). Copy ist auf Click-to-select umgeschrieben. Da mobil keine Range-Geste existiert, bekommt NUR diese eine Station eine `bMobile`-Variante — einmalige, minimale Erweiterung des Stations-Schemas; alle anderen Stationen haben einen Body für beide Viewports.
- **Kurier „Gelesenes verblasst“:** Ring zeigt auf den **Ungelesen-Filter** (Top-Level-Control aus dem Newsboard-Pass) — die Copy erklärt das Verblassen der Karten, der Filter ist der greifbare Griff dazu. Nie auf eine verblasste Karte zeigen.
- **Kiez-Daten „Kiez in Zahlen A4“:** ja, Anker = der Footer-Drucklink „⏙ Kiez in Zahlen · A4 drucken“. Pflicht 4 (scrollen, dann messen) greift hier naturgemäß.

**Zwei weitere Anker-Härtungen** (gleiche Regel, von mir beim Copy-Schreiben gezogen):
- **Kalender „Zusagen“:** RSVP lebt im Termin-Modal — die Tour öffnet nie Modals. Anker = Agenda-/Listen-Region (Container), die Copy erklärt den Weg („öffne einen Termin …“).
- **Marktplatz „Kontakt“:** Formular lebt auf der Detailseite. Anker = Anzeigen-Raster (Container), Copy erklärt.
- **Blog Station 3 → umbenannt zu „Mitreden & mitschreiben“:** der Forum-CTA lebt am Artikel-Ende (andere Route — Kapitel überquert nie eine Nav). Anker = das Aufruf-Modul „Schreib für den Kiez“ in der Index-Sidebar; die Copy deckt beides (Forum-CTA + Aufruf).

Approved. Ring + Scrim-z-Stapel + Kicker binden die Karte ausreichend an den Anker. **Ersatzregel:** die Karte sitzt maximal **24px** vom Ring entfernt (aktuell 16px — passt).

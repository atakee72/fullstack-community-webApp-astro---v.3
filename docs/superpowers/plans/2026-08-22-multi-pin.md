# Multi-pin for Official Announcements — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow up to three official announcements to be pinned at once (oldest pin displaced at the cap), on the server, the admin board, and the forum index.

**Architecture:** One dependency-pure rules module (`MAX_PINS`, `pickDisplaced`) shared by client and server; one server helper (`displaceForPin`) used by both admin API routes; the admin board and forum index switch from a single `pinnedItem` to a sorted `pinnedItems[]`. No schema change — `pinnedUntil` stays the only pin field.

**Tech Stack:** Astro 5 API routes, MongoDB driver, Svelte 5 runes islands, kiosk i18n (`src/lib/kiosk-i18n.ts`), playwright-cli for the browser gate.

**Spec:** `docs/superpowers/specs/2026-08-22-multi-pin-design.md`

## Global Constraints

- `MAX_PINS = 3`; pin duration stays `7 * 24 * 60 * 60 * 1000` ms (`PIN_DURATION_MS` in `create.ts`).
- Displacement removes exactly ONE pin (the earliest `pinnedUntil`), never more; the item being pinned is never a displacement candidate.
- Ordering everywhere: `pinnedUntil` descending (newest pin first).
- No test runner exists in this repo. Server logic is verified with a throwaway `tsx` script run from the repo root against the **dev** DB only (`MONGODB_URI` in `.env` points at `/mahalle-dev`; never touch `/mahalle`). Delete scratch scripts before committing.
- Client-imported modules must be dependency-pure (no `mongodb`/`connectDB` imports) — see root `CLAUDE.md` "Server-only modules bleeding into client bundles".
- i18n strings with typographic quotes („…“ / “…”) MUST be written via a python heredoc and byte-verified with `od -c` — the Edit tool normalizes Unicode quotes.
- `.svelte` changes need the browser gate (playwright-cli on port 4655, auth state at `~/.local/share/claude-mahalle/storage-state.json`; the seeded dev user `dev_admin` is admin). Never touch port 3000. Free 4655 afterwards with `fuser -k 4655/tcp`.
- Commit messages: short, no Claude signature/footer.

- [ ] **Step 1: Create the pure rules module**

```ts
// src/lib/announcements/pinRules.ts
// Dependency-pure pin rules shared by the admin island (optimistic UI)
// and the server helper. No mongodb/connectDB imports here — this file
// is bundled into a client:only="svelte" island.

export const MAX_PINS = 3;

interface Pinnable {
  _id?: unknown;
  pinnedUntil?: string | Date | null;
}

/** True when the item currently holds a pin. */
export function isCurrentlyPinned(item: Pinnable, now = Date.now()): boolean {
  return !!item.pinnedUntil && new Date(item.pinnedUntil).getTime() > now;
}

/**
 * Given the items that are currently pinned, return the ONE item that must
 * lose its pin so a new pin fits under MAX_PINS — or null if there's room.
 * The oldest pin (earliest pinnedUntil) goes. `excludeId` is the item being
 * (re-)pinned; it never displaces itself.
 */
export function pickDisplaced<T extends Pinnable>(pinned: T[], excludeId?: string): T | null {
  const candidates = pinned
    .filter((it) => isCurrentlyPinned(it))
    .filter((it) => String(it._id) !== excludeId);
  if (candidates.length < MAX_PINS) return null;
  return candidates
    .slice()
    .sort((a, b) => new Date(a.pinnedUntil!).getTime() - new Date(b.pinnedUntil!).getTime())[0];
}
```

- [ ] **Step 2: Create the server helper**

```ts
// src/lib/announcements/pin.ts
// SERVER-ONLY (takes a Db). Enforces the MAX_PINS invariant for official
// announcements: if the board is full, the oldest pin is cleared so the
// caller's pin fits. Single-admin app — the read-then-update window is
// sub-millisecond and accepted (same stance as the old single-pin code).
import { ObjectId, type Db } from 'mongodb';
import { pickDisplaced } from './pinRules';

export { MAX_PINS } from './pinRules';

export async function displaceForPin(db: Db, excludeId?: string): Promise<string | null> {
  const pinned = await db
    .collection('announcements')
    .find(
      { isOfficial: true, pinnedUntil: { $gt: new Date() } },
      { projection: { _id: 1, pinnedUntil: 1 } },
    )
    .toArray();
  const victim = pickDisplaced(pinned as any[], excludeId);
  if (!victim) return null;
  await db
    .collection('announcements')
    .updateOne({ _id: new ObjectId(String(victim._id)) }, { $set: { pinnedUntil: null } });
  return String(victim._id);
}
```

      if (!displaced || !displacedUntilISO || !createdId) return;
      try {
        const patch = (id: string, pinnedUntil: string | null) =>
          fetch(`/api/admin/announcements/${id}`, {
            method: 'PATCH',
            credentials: 'include',
            headers: { 'Content-Type': 'application/json' },

        const r2 = await patch(displaced._id, displacedUntilISO);
        if (!r2.ok) throw new Error(String(r2.status));
